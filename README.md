# Sorry Site

A small apology website built as a static page.

## Files

- `index.html` - page structure
- `styles.css` - visual design and responsive layout
- `script.js` - envelope reveal and playful button interactions

## Customize

Open `index.html` and change:

- the main headline
- the letter paragraphs
- the three reason cards
- the final question

## Run

You can open `index.html` directly in a browser.

If you want the `Copy custom link` button to work properly, serve the folder locally:

```powershell
cd E:\FUN\sorry-site
python -m http.server 8000
```
